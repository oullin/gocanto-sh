## Why this matters

`pnpm lint` → `turbo run lint` reports green in CI, but only `workspace/app`
runs a real linter. `workspace/writing` declares `"lint": "exit 0"` (a stub
that disguises the gap), and `domain`, `store`, and `llms` have no `lint`
script at all, so turbo silently skips them. All the shared TypeScript logic
(sanitization, search, fixtures, the llms generators) is unlinted. After this
plan, `pnpm lint` covers all five packages.

findings, STOP and report the counts instead of bulk-fixing.

**Verify**: `pnpm lint` → exit 0 and turbo's output lists the `lint` task for
